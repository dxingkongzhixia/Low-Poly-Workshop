## 本轮两项改动

### 1. 眼睛：用模板贴图，虹膜改蓝

不再自绘眼睛。头部网格保留模板自带的 6 材质与 96×80 脸部贴图，
启动时直接改贴图像素——虹膜是一组"低饱和青色"（g、b 同时明显高于 r），
把这 244 个像素按亮度重映射为蓝色：

```js
data[i]     = 28  + lum * 0.16;   // r
data[i + 1] = 88  + lum * 0.40;   // g
data[i + 2] = 170 + lum * 0.45;   // b
```

实测结果：蓝瞳 **244 px**，平均 RGB **(53, 151, 241)**。

身体/手臂/腿仍然剥离模板外观（统一为共享皮肤材质），只有脸保留模板贴图。

### 2. 腿与靴子

按参考图重做：

| 项 | 处理 |
|---|---|
| 靴筒高度 | 降到 **y 0.285**（中筒），上面露出小腿皮肤 |

| 白色 V 形 | 靴面 y 0.262 处向下人字 |

## 几何做法

可见主体**没有使用** `BoxGeometry` / `SphereGeometry` / `CylinderGeometry`。

| 用途 | 方法 |
|---|---|
| 方块躯干/四肢/靴/袖 | `blockStack`（4 边轴对齐截面放样）/ `block` |
| 脸、刘海、鬓角翼、衣片、下摆、星徽章、护膝 | `shapeExtrude`（硬边轮廓挤出，支持凹多边形） |
| 圆眼 | `circlePoints` + `shapeExtrude` |

三角面控制：被遮挡的端面传 `{capStart:false, capEnd:false}`。

## 已修正的问题（均为实测定位）

| 问题 | 根因 | 修正 |
|---|---|---|
| 部件"没生成"、正面能看穿 | `loft` 绕序取决于环的叠放方向，朝内时正面被背面剔除 | kit 内置 `orientOutward()`，按质心测量法向量自动翻转 |
| 发帽切在眼睛上 / 颅顶露皮肤 | 头部最宽处在 y 1.66–1.78（±0.514），不是在中间 | 发帽在该区间加宽到 ±0.56，下沿抬到 y 1.50 |
| 手插进外套下摆 | 手臂固定在外摆前的 x ±0.29，下摆 rx 到 0.45 | 找到 `reference-elbow-0/1` 的父组外摆 0.40 rad；下摆收窄 |
| 马尾穿到地板下 | 马尾长 2.1，从 y 1.56 往下 | 长度收到 1.56，尖端落在 y ≈ 0.23 |
| 兜帽/外套插进头 | Q 版头部从 y 1.065 就是 ±0.33 的宽块，与躯干顶部重叠 | 服装全部压到 y ≤ 1.06；兜帽加宽并后移 |
| 快速切换变体后网格翻倍 | 模型还在加载时并发构建 | 加构建令牌串行化 + 加载期间禁用选择器 |

## 与参考图的差距（诚实说明）

结构、比例、预算、关节都已达标，但**外观细节还达不到 2D 设定图的完成度**：

- 头发是"整块"造型，没有参考图那种多片分束与尖锋层次
- 面部只有圆眼+嘴+腮红，没有参考图的眼线细节与表情
- 外套下摆是左右两片+后片，未做参考图的多片开口
- 白色装饰条偏碎，视觉上像噪点而不是干净的衣缝
- 方块风格本身会压掉参考图的柔和渐变

**这是个 2D 精绘设定图 vs 程序化低模的现实差距。** 想再接近，需要逐部件对着图调顶点，
或者改用 DCC/体素工具手动建模（本技能另有 `projects/voxel-character/` 体素路线）。
