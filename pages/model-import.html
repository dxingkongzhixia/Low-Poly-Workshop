模型导入

吃别的建模工具的产物：.vox（VoxiGen / MagicaVoxel）逐体素解析后三轴贪心合并成方块； .glb/.gltf/.obj 按连通分量拆成轴对齐盒。
调好参数后导出 GLB，或下载「部件 JSON」在部件编辑器里整块导入。

1 · 载入文件 —

把 .vox / .glb / .gltf / .obj 拖到这里
精度
单一闭合网格开，多网格关

Meshy / TRELLIS 这类平滑网格要勾上「体素化」：先采样成体素再贪心合并。 判实心只在模型是一整片闭合网格时才对；如果导入的是游戏模型那种一堆分离盒子壳，关掉它， 否则盒子和盒子之间的空隙会被灌实糊成一坨。

3 · 导出

在部件编辑器里：把文件放同目录 → EditorAPI.importVox('/x.vox',{parent:'head',fitHeight:0.62})； 或面板「导入体素 / 模型」。部件 JSON 可用 EditorAPI.addPartJSON({...}) 整块加入。
