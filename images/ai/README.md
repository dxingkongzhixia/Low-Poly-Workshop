# images/ai —— AI 工作流卡片的三张图

启动页（`index.html`）的「AI 工作流」三张卡片用这里的图。
**文件名必须完全对上**，否则卡片会退回文字占位（不会报错）。

| 文件名 | 用在哪张卡 | 建议内容 | 建议尺寸 |
|---|---|---|---|
| `ai-agent.png` | **AI 工作流说明** | 「AI Agent」发光方块（深蓝科技风） | 方图，≥600×600 |
| `api.png` | **AI 操作手册** | 云 + 连线到各种设备（蓝色扁平图标风） | 横图，≥600×400 |
| `ref.png` | **EditorAPI 命令速查** | 「REF」文字 + 浅蓝背景 | 横图，≥600×400 |

## 怎么放

把三张图**另存为**这三个文件名，丢进本目录即可：

```
images/ai/ai-agent.png
images/ai/api.png
images/ai/ref.png
```

存完刷新 `http://localhost:8765/index.html` 就能看到（不用重启服务器）。

## 说明

- 卡片缩略图区域大约是 **16:9 裁切**（`object-fit` 会居中裁），所以主体别太靠边。
- 想换风格：直接覆盖同名文件即可，代码不用改。
- 想加第四张：在 `index.html`「AI 工作流」区块里照抄一张 `<a class="card">` 即可。
