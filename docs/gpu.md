# 显卡与故障排查 —— 没有显卡怎么办

> 本工具靠 **WebGL** 在浏览器里实时渲染 3D。有没有显卡、有没有开硬件加速，
> 直接决定「能用 / 很卡 / 打不开」。主界面和角色实验室都会自动检测并提示。

---

## 1. 先看你的状态

**主界面 `pages/index.html` →「系统状态」→「显卡 / 渲染后端」**，或者直接看
**角色实验室 →「比例 / 动作」最上面那条**。也可以在 Console 里：

```js
EditorAPI.gpu()
// { supported, webgl, vendor, renderer, software, tier, maxTexture, level, title, steps }
```

四种结果：

| `level` | 含义 | 能干什么 |
|---|---|---|
| `ok` | 硬件加速正常 | 全部功能 |
| `unknown` | 能用，但浏览器藏了型号（常见于 Firefox） | 全部功能；想知道真实型号开 `chrome://gpu` |
| `warn` | **软件渲染**（SwiftShader / llvmpipe）—— 就是「没有显卡」 | 能跑但很慢，按 §3 降级 |
| `blocked` | 没有可用的 WebGL | 按 §2 修 |

---

## 2. 完全打不开（`blocked`）：按顺序试

1. **换浏览器**：Chrome / Edge / Firefox 最新版。
   IE、部分国产内核浏览器、以及被 IT 策略锁掉的浏览器没有 WebGL。
2. **打开硬件加速**：
   - Chrome / Edge：`设置` → `系统` → 打开「**使用硬件加速模式（如果可用）**」→ **重启浏览器**（关掉全部窗口）。
   - Firefox：`设置` → `常规` → `性能` → 取消「使用推荐的性能设置」→ 勾选「使用硬件加速」。
3. **看 `chrome://gpu`**：
   在地址栏打开，找 **WebGL** 和 **WebGL2** 两行。
   - `Hardware accelerated` → 正常
   - `Software only` / `Disabled` → 显卡驱动有问题，走第 4 步
   - 整页红字 → 看最上面的「Problems Detected」，通常写着原因
4. **更新显卡驱动**：去 **NVIDIA / AMD / Intel 官网**下驱动，**别用系统自带的通用驱动**。
   装完重启。核显（Intel UHD / AMD Radeon Graphics）也够用，但驱动要是新的。
5. **虚拟机 / 远程桌面 / 无头服务器**通常**没有 GPU**：
   本工具必须在**有显卡的本机浏览器**里打开。在服务器上跑 `tools/_serve.js` 没问题，
   但浏览器要在有显卡的机器上。
6. **公司电脑被策略锁了**：`chrome://flags` 里搜 `WebGL` 确认没被禁；问 IT 要例外。

---

## 3. 能用但是软件渲染（`warn`）：降级建议

软件渲染是浏览器拿 CPU 顶替 GPU，**帧率可能只有个位数**，而且会吃满一个核心。

| 做法 | 效果 |
|---|---|
| 浏览器窗口调小（别全屏） | 直接减少像素量，最有效 |
| 角色实验室：**只开一个角色**，别同屏 6 个高模 | 高模几千个网格，CPU 顶不住 |
| 关掉「自动旋转」和动画（选静止的待机姿态） | 不重绘就不卡 |
| 别用「导出 GLB」 | 导出会一次性把整个场景转成二进制，容易卡死 |
| 编辑器里少用 `boxify` 大角色 + 高细分 `geo` 图元 | 面数越高越慢 |
| 换一台有独显的机器 | 根治 |

> 软件渲染下**功能是完整的**，只是慢。质量门、保存、缓存都不依赖显卡性能。

---

## 4. 页面说「连不上本地服务」

保存 / 缓存 / Agent 记录 / 新增模型列表都走 `tools/_serve.js` 的 `/api/*`。
如果主界面「系统状态」里显示 **连不上本地服务**：

1. 确认服务器在跑：双击 **`启动-低模工坊.bat`**，或者手动
   ```
   cd D:\ROTK\three.js
   node tools/_serve.js
   ```
   看到 `低模工坊 · serving on 8765` 就对了。
2. 用 **`http://localhost:8765/`** 打开页面，**不要**直接双击 `pages/index.html`
   （`file://` 下 fetch 和 ES module 都不工作）。
3. 端口被占：`netstat -ano | findstr 8765`，或者换个端口
   `set PORT=8766 && node tools/_serve.js`。
4. 防火墙弹窗要点「允许」。

## 5. 性能参考（本机实测）

| 场景 | 硬件加速 | 软件渲染 |
|---|---|---|
| 编辑器 + 24 部件（boxify 拉普兰德） | 流畅 | 卡但可用 |
| 实验室单角色低模 | 流畅 | 可用 |
| 实验室切高模（1000+ 网格） | 流畅 | 明显掉帧 |
| 跑一次 8 门 + 8 方位转盘（512²） | 约 0.3~0.5 秒 | 数秒 |

> 质量门的渲染是**离屏正交 512²**，比实时视口轻，所以软件渲染下也能跑门，
> 只是慢一点。
